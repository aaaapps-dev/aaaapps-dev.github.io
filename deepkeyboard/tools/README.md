# Deep Keyboard phrase dictionaries

`build_phrases.py` builds keyboard dictionaries with next-word predictions.
Run it from GitHub: Actions › Build phrase dictionaries › Run workflow.

Text sources: Leipzig Corpora Collection, Leipzig University (https://wortschatz.uni-leipzig.de),
licence CC BY 4.0. Word lists: AOSP LatinIME dictionaries (Apache 2.0).
`dicttool.jar` is built from AOSP LatinIME (Apache 2.0).
